# Редуктор режимов машинного телеграфа

## Назначение

Редуктор — это дополнительный орган управления поверх машинного телеграфа.  
Он не заменяет телеграф и не превращает управление ходом в обычный throttle.  
Его задача — тонко уменьшать мощность выбранного режима относительно предыдущего режима.

Машинный телеграф выбирает дискретный режим хода:

```text
СТОП → МАЛЫЙ → СРЕДНИЙ → ПОЛНЫЙ
```

Редуктор выбирает промежуточное значение между предыдущим и текущим выбранным режимом.

---

## Главная логика

Если выбран режим `СРЕДНИЙ ХОД`, редуктор работает в диапазоне:

```text
МАЛЫЙ ХОД → СРЕДНИЙ ХОД
```

Если выбран режим `ПОЛНЫЙ ХОД`, редуктор работает в диапазоне:

```text
СРЕДНИЙ ХОД → ПОЛНЫЙ ХОД
```

То есть редуктор не уменьшает скорость от нуля.  
Он уменьшает только прирост между предыдущей ступенью и выбранной ступенью.

---

## Положение слайдера

Редуктор — вертикальный слайдер, визуально имитирующий работу клапана.

```text
ВВЕРХ  = полностью закрыт = 100% текущего выбранного режима
ВНИЗ   = полностью открыт = 0% текущего режима = 100% предыдущего режима
```

Промежуточные положения дают промежуточную мощность между предыдущим и текущим режимом.

```text
     CLOSED
       ▲
       │ 100% выбранного режима
       │
       │ 75%
       │
       │ 50%
       │
       │ 25%
       │
       │ 0% выбранного режима
       ▼
      OPEN
```

---

## Что означает процент

Процент редуктора — это не процент общей мощности корабля.

Правильнее понимать его так:

```text
процент перехода от предыдущего режима к выбранному режиму
```

Пример:

```text
Выбран режим: ПОЛНЫЙ ХОД
Предыдущий режим: СРЕДНИЙ ХОД

Редуктор 100% → полный ход
Редуктор 75%  → 75% перехода от среднего к полному
Редуктор 50%  → середина между средним и полным
Редуктор 25%  → чуть выше среднего
Редуктор 0%   → ровно средний ход
```

---

## Пример с условными скоростями

Допустим, режимы имеют такие целевые скорости:

```text
СТОП       = 0 узлов
МАЛЫЙ      = 8 узлов
СРЕДНИЙ    = 16 узлов
ПОЛНЫЙ     = 24 узла
```

### Если выбран СРЕДНИЙ ХОД

Диапазон редуктора:

```text
МАЛЫЙ ХОД → СРЕДНИЙ ХОД
```

Результат:

```text
Редуктор 100% → 16 узлов
Редуктор 75%  → 14 узлов
Редуктор 50%  → 12 узлов
Редуктор 25%  → 10 узлов
Редуктор 0%   → 8 узлов
```

### Если выбран ПОЛНЫЙ ХОД

Диапазон редуктора:

```text
СРЕДНИЙ ХОД → ПОЛНЫЙ ХОД
```

Результат:

```text
Редуктор 100% → 24 узла
Редуктор 75%  → 22 узла
Редуктор 50%  → 20 узлов
Редуктор 25%  → 18 узлов
Редуктор 0%   → 16 узлов
```

## Работа по режимам

Рекомендуемая логика:

```text
Режим телеграфа     Диапазон редуктора

СТОП                редуктор не влияет
МАЛЫЙ ВПЕРЕД        от СТОП до МАЛЫЙ ВПЕРЕД
СРЕДНИЙ ВПЕРЕД      от МАЛЫЙ ВПЕРЕД до СРЕДНИЙ ВПЕРЕД
ПОЛНЫЙ ВПЕРЕД       от СРЕДНИЙ ВПЕРЕД до ПОЛНЫЙ ВПЕРЕД
ЗАДНИЙ ХОД          от СТОП до ЗАДНИЙ ХОД
```

Для `СТОП` редуктор лучше отключать или визуально блокировать, потому что у стопа нет полезного верхнего диапазона.

Для `ЗАДНЕГО ХОДА`, если в игре пока один режим назад, можно использовать простую схему:

```text
Редуктор 100% → полный задний ход
Редуктор 50%  → половина заднего хода
Редуктор 0%   → стоп
```

---

## Важно: редуктор меняет приказ, а не фактическую скорость

Редуктор не должен напрямую менять текущую скорость корабля.

Он должен менять целевую скорость или целевую мощность, а уже модель движения корабля должна инерционно вести фактическую скорость к этому значению.

Схема:

```text
Игрок выбирает режим машинного телеграфа
        ↓
Редуктор уточняет процент выбранного режима
        ↓
Получается целевая скорость / целевая тяга
        ↓
Модель движения плавно разгоняет или тормозит корабль
```

Так сохраняется ощущение тяжелого корабля, который не реагирует мгновенно.

## UI-представление

В интерфейсе желательно показывать:

```text
TELEGRAPH: FULL AHEAD
REDUCER:   65%
TARGET:    21.2 kt
ACTUAL:    18.7 kt
```

Или компактно:

```text
FULL AHEAD / 65%
Target: 21.2 kt
Actual: 18.7 kt
```

Важно, чтобы игрок понимал разницу между:

```text
выбранным режимом телеграфа
процентом редуктора
целевой скоростью
фактической скоростью корабля
```

---

## Объяснение метафоры клапана

На первый взгляд может показаться странным, что:

```text
закрыто = больше мощности
открыто = меньше мощности
```

Но это можно объяснить как работу редукционного или сбросного клапана:

- клапан открыт — часть давления сбрасывается, выбранный режим ослаблен;
- клапан закрыт — давление не сбрасывается, выбранный режим передается полностью.

Поэтому такая логика может быть оправдана визуально и технически.

## Возможные названия

Слово `редуктор` можно оставить, но по смыслу также подходят:

```text
ходовой редуктор
ограничитель хода
регулятор подачи
редукционный клапан
ходовой клапан
```

Для интерфейса лучше короткое название:

```text
REDUCER
```

или:

```text
РЕДУКТОР ХОДА
```

## Итоговая модель

Итоговая логика:

```text
Машинный телеграф выбирает верхнюю ступень хода.
Редуктор смешивает выбранную ступень с предыдущей.
0%   = предыдущий режим
100% = выбранный режим
Промежуточные значения = плавный переход между ними.
Фактическая скорость меняется инерционно.
```

Такой редуктор добавляет точное управление скоростью, но сохраняет дискретную природу машинного телеграфа и ощущение управления большой инерционной машиной.
