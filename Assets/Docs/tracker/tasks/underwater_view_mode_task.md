# Underwater View Mode Task

## Задача
Добавить возможность обзора под водой.

## Что нужно продумать
- Сценарии включения и выключения подводного обзора во время игры.
- Поведение камеры под водой: ограничения движения, углы обзора и переходы между режимами.
- Визуальные особенности подводного режима: цветокоррекция, мутность, световые эффекты и читаемость объектов.
- Совместимость режима с текущими камерами, UI и системами наведения.
- Ограничения по производительности и fallback-поведение на слабых конфигурациях.

## Ожидаемый результат
Подготовлена задача на реализацию режима обзора под водой с понятным управлением, визуальной читаемостью и корректной интеграцией в существующую систему камер.
