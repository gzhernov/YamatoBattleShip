# Spotter AI Task

## Задача
Добавить ИИ корректировщика.

## Что нужно продумать
- Роль ИИ корректировщика в бою: наблюдение за целью, поддержка наведения и передача поправок.
- Базовые состояния и цикл работы: поиск цели, сопровождение, выдача корректировки, восстановление после потери контакта.
- Правила взаимодействия с существующими системами выбора цели, огневого решения и артиллерийского интерфейса.
- Ограничения и задержки в работе корректировщика, чтобы поведение оставалось понятным и читаемым.
- Формат обратной связи для игрока через UI-индикаторы статуса корректировщика.

## Ожидаемый результат
Подготовлена задача на реализацию ИИ корректировщика с описанием его состояний, логики работы и интеграции с текущими боевыми системами.
