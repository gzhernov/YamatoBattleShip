# Панель управления артиллерийским огнём

## Назначение

Панель отвечает за отображение состояния цели, качества огневого решения, состояния артиллерийских башен и ручное управление залпом.

Панель рассматривается как **полная симуляторная версия**, а не минимальный HUD-вариант.

Расположение: **правый верхний угол экрана**.

---

## Общая структура

```text
FULL ARTILLERY PANEL
├── HEADER
├── TARGET INFO
├── FIRE SOLUTION
├── GUN STATUS
└── FIRE CONTROL
```

---

│ Курс: 075°       Ракурс: борт 82°      │
├────────────────────────────────────────┤
│ FIRE SOLUTION                          │
│ Фаза: Пристрелка                       │
│ Данные: стабильные                     │

## 1. HEADER

Верхняя строка панели.

### Содержит

- Название панели: `АРТИЛЛЕРИЯ`
- Статус захвата цели: `●LOCK`

### Возможные состояния статуса

```text
● NO TARGET — цели нет
● TRACKING  — цель сопровождается
● LOCK      — цель захвачена
● LOST      — цель потеряна
● PAUSE     — огонь поставлен на паузу
```

---

## 2. TARGET INFO

Блок содержит данные о цели и её движении.

### Структура

```text
TARGET INFO
├── Цель
├── Пеленг
├── Дальность
├── Курс
├── Скорость
├── Скорость сближения
└── Ракурс
```

### Рекомендуемое отображение

```text
│ TARGET INFO                            │
│ Цель: Yamato                           │
│ Пеленг: 042°     Скорость: 24 уз.      │
│ Дист: 12.4 км    Сбл: +8 уз.           │
│ Курс: 075°       Ракурс: борт 82°      │
```

### Логика блока

`TARGET INFO` должен отвечать на вопрос:

```text
Что это за цель, где она находится и как она движется?
```

В этот блок не нужно добавлять попадания, промахи или статистику стрельбы. Эти данные относятся к огневому решению.

---

## 3. FIRE SOLUTION

Блок показывает качество огневого решения и результат последнего залпа.

### Структура

```text
FIRE SOLUTION
├── Фаза стрельбы
├── Качество данных
├── Текущая точность
├── Эллипс / разброс
├── Время до прилёта
├── Результат последнего залпа
├── Коррекция
└── Текущий фактор / предупреждение
```

### Рекомендуемое отображение

```text
│ FIRE SOLUTION                          │
│ Фаза: Пристрелка                       │
│ Данные: стабильные                     │
│ Точность: 63%  ██████░░░░              │
│ Разброс: 210 × 85 м                    │
│ До прилёта: 8.2 c                      │
│ Последний: 2/6 попаданий               │
│ Коррекция: недолёт 120 м               │
│ Фактор: цель маневрирует               │
```

### Возможные фазы

```text
Нет цели
Захват цели
Пристрелка
Ожидание падения
Корректировка
Беглый огонь
Перезарядка
Огонь на паузе
```

### Состояния строки "Последний"

```text
Последний: —
Последний: ожидание
Последний: 0/6 попаданий
Последний: 2/6 попаданий
```

### Возможные коррекции

```text
Коррекция: недолёт 120 м
Коррекция: перелёт 80 м
Коррекция: левее 40 м
Коррекция: правее 60 м
Коррекция: накрытие
```

---

## 4. GUN STATUS

Блок показывает физическое состояние артиллерии.

### Структура

```text
GUN STATUS
├── Состояние башен
├── Фактически заряженный снаряд / заряд
├── Выбранный снаряд / заряд
└── Время до следующего залпа
```

### Рекомендуемое отображение

```text
│ GUN STATUS                             │
│ Башни: [✓] [✓] [⟳]                     │
│ Заряжен: HE / Standard                 │
│ Выбрано: AP / Special                  │
│ Следующий залп: 11.4 c                 │
```

### Обозначения башен

```text
✓  — башня готова
⟳  — башня доворачивает
↻  — башня перезаряжается
×  — башня вне сектора / не может стрелять
```

### Важный UX-момент

Нужно различать:

```text
Заряжен — что реально находится в орудиях сейчас
Выбрано — что игрок выбрал для следующей зарядки
```

Пример:

```text
Заряжен: HE / Standard
Выбрано: AP / Special
```

Это важно для симуляторной игры, потому что выбранный тип боеприпаса может не совпадать с уже заряженным.

---

## 5. FIRE CONTROL

Нижний интерактивный блок. Отвечает за команды игрока.

### Структура

```text
FIRE CONTROL
├── Выбор снаряда
├── Выбор заряда
├── Переключатель огня
├── Количество залпов
└── Кнопка начала залпа
```

### Рекомендуемое отображение

```text
│ FIRE CONTROL                           │
│ Снаряд: [  HE  ] [  AP  ]              │
│         [HE-ER ] [AP-Dye]              │
│ Заряд:  [Reduced] [Standard]           │
│         [Special]                      │
│ Огонь:  [АКТ] [ПАУЗА]                  │
│ Залпы:  [1] [2] [3]                    │
│ [          НАЧАТЬ ЗАЛП          ]      │
```

### Типы снарядов

```text
HE      — фугасный
AP      — бронебойный
HE-ER   — фугасный увеличенной дальности
AP-Dye  — бронебойный с красителем / трассирующей маркировкой залпа
```

### Типы заряда

```text
Reduced  — уменьшенный заряд
Standard — стандартный заряд
Special  — специальный / усиленный заряд
```

### Переключатель огня

```text
[АКТ]   — огонь разрешён
[ПАУЗА] — огонь приостановлен
```

Пауза огня:

```text
- не отменяет уже летящие снаряды;
- не сбрасывает захват цели;
- не сбрасывает точность;
- запрещает новые автоматические залпы;
- может блокировать ручной залп;
- может останавливать продолжение серии залпов.
```

### Количество залпов

```text
[1] [2] [3]
```

Игрок выбирает, сколько залпов подряд выполнить с текущими параметрами.

## Визуальные рекомендации

### Общий стиль

- Полупрозрачный тёмный фон.
- Тонкие рамки.
- Компактный технический шрифт.
- Чёткое разделение блоков горизонтальными линиями.
- Акцентные цвета для статусов.

### Цветовая логика

```text
Зелёный / голубой — нормальное состояние, захват, готовность
Жёлтый / оранжевый — предупреждение, пристрелка, корректировка
Красный — ошибка, запрет, потеря цели
Серый — неактивный элемент
```

### Размер и положение

```text
Положение: правый верхний угол
Ширина: примерно 360–420 px
Высота: зависит от масштаба UI
Отступ от края экрана: 20–30 px
```

---

## Логика разделения блоков

```text
TARGET INFO
Данные цели: кто, где, как движется.

FIRE SOLUTION
Качество огневого решения: точность, разброс, результат, коррекция.

GUN STATUS
Физическое состояние артиллерии: башни, заряжено, следующий залп.

FIRE CONTROL
Команды игрока: снаряд, заряд, пауза, количество залпов, начать залп.
```
