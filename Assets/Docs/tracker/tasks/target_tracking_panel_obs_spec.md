# Target Tracking Panel — компактная панель слежения за целью

## Назначение

Панель показывает выбранную цель и основные параметры для ведения огня:

- имя цели;
- тип цели;
- дальность;
- курс;
- скорость;
- статус сопровождения;
- количество наблюдательных постов, прикрепленных к цели;
- состояние назначения наблюдательных постов.

Бинокль в заголовке является кнопкой быстрого наведения камеры на выбранную цель.

---

## ASCII-макет

```text
+---------------- TARGET ----------------+
| [BINOCULAR] BB-01 YAMATO        [BB]   |
| Range: 12.4 km        Track: 78%       |
| Course: 087°          Speed: 21.5 kt   |
| Status: TRACKED                        |
+-----------------------------------------+
| Obs [-] ■■▒▒□□□□□□□□ [+] 2/12          |
+-----------------------------------------+
```

---

## Расшифровка элементов

```text
[BINOCULAR] = кликабельная кнопка наведения камеры на цель

BB-01 YAMATO = имя цели
[BB]         = короткий тип цели / класс корабля

Range        = дистанция до цели
Track        = качество сопровождения цели
Course       = курс цели
Speed        = скорость цели
Status       = состояние сопровождения

Obs          = наблюдательные посты
[-]          = снять один наблюдательный пост с цели
[+]          = назначить один свободный наблюдательный пост на цель

■■           = посты уже назначены и работают
▒▒           = посты назначаются, идет задержка
□□□□□□□□   = свободные / не назначенные посты

2/12         = 2 активных поста из 12 доступных
```

---

## Состояния сегментов Obs

```text
■ = active
    Пост назначен на цель и уже работает.

▒ = assigning
    Пост назначается, идет задержка перед вступлением в работу.

□ = free
    Пост свободен или не назначен на эту цель.
```

Дополнительно, для будущего расширения:

```text
× = unavailable
    Пост недоступен, поврежден или заблокирован.

! = warning
    Пост работает с проблемой, например плохая видимость или потеря точности.
```

Для MVP достаточно трех состояний:

```text
■ active
▒ assigning
□ free
```

## Поведение кнопки бинокля

```text
BinocularButton

При нажатии:
- камера поворачивается / фокусируется в сторону выбранной цели.

Normal:
- цель выбрана;
- цель доступна;
- камера может быть наведена.

Hover:
- иконка или рамка подсвечивается.

Pressed:
- короткая анимация нажатия.

Disabled:
- цели нет;
- цель уничтожена;
- цель потеряна;
- камера уже недоступна для автонаведения.

Tracking:
- камера уже сфокусирована на этой цели.
```

Tooltip:

```text
Навести камеру на цель
```

---

## Поведение кнопки [+]

```text
[+] назначить один свободный наблюдательный пост на текущую цель.

Кнопка активна, если:
- есть выбранная цель;
- цель не уничтожена;
- есть свободные observation posts;
- не достигнут лимит постов на эту цель.

После нажатия:
- появляется один сегмент ▒;
- запускается задержка назначения;
- после завершения задержки ▒ превращается в ■.
```

Пример:

```text
До нажатия:
Obs [-] ■■□□□□□□□□□□ [+] 2/12

После нажатия:
Obs [-] ■■▒□□□□□□□□□ [+] 2/12

После задержки:
Obs [-] ■■■□□□□□□□□□ [+] 3/12
```

---

## Поведение кнопки [-]

```text
[-] снять один наблюдательный пост с текущей цели.

Кнопка активна, если:
- на цель назначен хотя бы один активный пост;
- либо есть пост в состоянии assigning, который можно отменить.

Приоритет снятия:
1. сначала отменять посты в состоянии assigning;
2. затем снимать активные посты.
```

Пример:

```text
До нажатия:
Obs [-] ■■▒▒□□□□□□□□ [+] 2/12

После одного нажатия:
Obs [-] ■■▒□□□□□□□□□ [+] 2/12

После второго нажатия:
Obs [-] ■■□□□□□□□□□□ [+] 2/12

После третьего нажатия:
Obs [-] ■□□□□□□□□□□□ [+] 1/12
```
