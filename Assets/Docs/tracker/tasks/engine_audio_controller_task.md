# Engine Audio Controller Task

## Задача
Добавить звуки работающего двигателя с аудио-контроллером.

## Что нужно продумать
- Какие слои звука нужны: idle/нагрузка, ускорение, реверс, переходы между режимами телеграфа.
- Источник параметров для аудио: режим телеграфа, фактическая скорость, ускорение, проскальзывание (если есть), нагрузка.
- Плавность кроссфейдов и реакцию на переключение режимов без резких скачков громкости/тона.
- Точки интеграции: ShipPropulsionModel/движение, UI телеграфа, общая аудио-архитектура проекта.
- Производительность и управление количеством источников (особенно при нескольких кораблях).

## Ожидаемый результат
Подготовлена задача на реализацию аудио-контроллера двигателя, который обеспечивает правдоподобную реакцию звука на управление ходом и состояние движения корабля.
