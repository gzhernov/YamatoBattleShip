# HUD Binocular Element Task

## Задача
Добавить бинокль как элемент HUD.

## Что нужно продумать
- Расположение и размер элемента бинокля в интерфейсе без перегрузки основного экрана.
- Сценарии использования: активация, деактивация, состояние наведения и поведение при отсутствии выбранной цели.
- Визуальные состояния элемента: normal, hover, active, disabled и понятная индикация текущего режима.
- Связь с существующими системами камеры, выбора цели и боевого интерфейса.
- Читаемость и удобство использования на разных разрешениях.

## Ожидаемый результат
Подготовлена задача на реализацию HUD-элемента бинокля с понятной интерактивностью и интеграцией в текущий боевой интерфейс.
