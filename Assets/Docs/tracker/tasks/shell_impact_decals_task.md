# Shell Impact Decals Task

## Задача
Добавить систему декалей в месте попадания снаряда.

## Что нужно продумать
- Какие типы следов должны появляться при попадании: копоть, сколы краски, пробоины, следы осколков или следы рикошета.
- Как определять точку и ориентацию декали на корпусе корабля или другой поверхности после попадания.
- Как учитывать тип поверхности, угол попадания и мощность снаряда при выборе визуального эффекта.
- Ограничение количества декалей, время их жизни и стратегию очистки для сохранения производительности.
- Совместимость системы декалей с текущими визуальными эффектами попаданий, водой и материалами корабля.

## Ожидаемый результат
Подготовлена задача на реализацию системы декалей в местах попадания снарядов, которая усиливает визуальную обратную связь от боя и остается управляемой по производительности.
