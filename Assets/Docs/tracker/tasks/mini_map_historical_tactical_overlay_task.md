# Mini Map Historical Tactical Overlay Task

## Задача
Добавить мини-карту с тактическим отображением траектории движения цели и залпов в стиле исторических схем.

## Что нужно продумать
- Формат мини-карты и ее размещение в интерфейсе без перегрузки основного HUD.
- Отображение траектории движения цели с читаемой историей перемещений.
- Визуализацию залпов и направлений огня в стилистике исторических тактических схем.
- Частоту обновления и фильтрацию данных, чтобы карта оставалась понятной в динамичном бою.
- Совместимость с текущими системами выбора цели и боевого интерфейса.

## Ожидаемый результат
Подготовлена задача на мини-карту с тактическим историческим оверлеем траекторий и залпов, повышающим читаемость боя.
