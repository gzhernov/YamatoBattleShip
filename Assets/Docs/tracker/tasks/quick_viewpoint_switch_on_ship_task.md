# Quick Viewpoint Switch On Ship Task

## Задача
Добавить быстрое перемещение точки обзора на самом корабле.

## Что нужно продумать
- Набор доступных точек обзора на корабле и правила переключения между ними.
- Способ быстрого вызова и переключения точки обзора во время боя.
- Плавность перехода камеры и ограничения, чтобы не терялась ориентация игрока.
- Совместимость с режимами прицеливания, биноклем и остальными камерами проекта.
- Визуальную обратную связь, показывающую текущую активную точку обзора.

## Ожидаемый результат
Подготовлена задача на быстрый переход между точками обзора на корабле с удобным управлением и предсказуемым поведением камеры.
