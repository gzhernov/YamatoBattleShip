# Funnel Smoke Controller Task

## Задача
Добавить контроллер дыма из трубы.

## Что нужно продумать
- Источник параметров для дыма: режим телеграфа, фактическая скорость, ускорение/торможение, нагрузка двигателя.
- Визуальные параметры дыма: плотность, цвет, скорость эмиссии, размер частиц, направление с учетом ветра.
- Поведение при смене режима хода и резких переходах (рывок, стоп, задний ход).
- Интеграцию с существующими визуальными контроллерами корабля без влияния на кинематику.
- Производительность и уровни качества (дистанции, LOD, ограничение частиц).

## Ожидаемый результат
Подготовлена задача на реализацию контроллера дыма из трубы с зависимостью от режима движения и управляемыми параметрами качества.
