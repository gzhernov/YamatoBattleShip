# Crew Management Panel UI Only Task

## Задача
Добавить панель управления персоналом, включающую только механики интерфейса без геймплея.

## Что нужно продумать
- Структуру экрана и основные UI-блоки панели: список персонала, карточка выбранного члена экипажа, фильтры и действия.
- Навигацию и интерактивные элементы интерфейса: выбор, сортировка, переключение вкладок, состояния кнопок.
- Визуальные состояния панели: пустой список, загрузка, выбранная запись, недоступное действие.
- Формат и отображение тестовых данных, чтобы панель выглядела рабочей без подключения геймплейной логики.
- Консистентность с текущим UI-стилем проекта и читаемость на целевых разрешениях.

## Ожидаемый результат
Подготовлена задача на реализацию UI-панели управления персоналом без геймплейной интеграции, с понятной структурой, интерактивностью и демонстрационными состояниями интерфейса.
