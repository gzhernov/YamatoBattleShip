# Engine Controller Sequential Modes Task

## Задача
Продумать и добавить контроллер двигателя.

## Проблема
Двигатель должен работать по определенным правилам, а переключение режимов не должно быть мгновенным при выборе далекого режима.

## Что нужно продумать
- Последовательное переключение режимов двигателя через промежуточные ступени телеграфа.
- Правила перехода между режимами: задержки, время реакции, ограничения на резкую смену вперед/назад.
- Разницу между приказом телеграфа, фактическим режимом двигателя и текущей скоростью корабля.
- Как контроллер двигателя взаимодействует с `ShipPropulsionModel`, UI телеграфа, звуками двигателя и визуальными эффектами.
- Какие параметры должны быть настраиваемыми для разных кораблей: время перехода, инерция, допустимые режимы, штрафы за резкие команды.
- Как игроку показывать процесс перехода режима, чтобы управление оставалось понятным.

## Ожидаемый результат
Подготовлена задача на механику контроллера двигателя, где режимы переключаются последовательно по правилам, а не мгновенно, с понятной связью между приказом телеграфа, состоянием двигателя и фактическим движением корабля.
