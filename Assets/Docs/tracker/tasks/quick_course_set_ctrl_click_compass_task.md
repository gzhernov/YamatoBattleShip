# Quick Course Set Ctrl Click Compass Task

## Задача
Добавить функцию быстрого задания курса по `Ctrl + Click` с отрисовкой круга компаса и стрелки.

## Что нужно продумать
- Логику ввода `Ctrl + Click` и правила вычисления нового курса относительно текущего положения корабля.
- Визуальную отрисовку круга компаса и стрелки направления с понятной обратной связью для игрока.
- Поведение при отмене, повторном назначении курса и конфликте с другими действиями мыши.
- Интеграцию с текущей системой управления курсом и отображением навигационных данных.
- Ограничения и валидации, чтобы команда курса оставалась предсказуемой и удобной в бою.

## Ожидаемый результат
Подготовлена задача на быстрый ввод курса по `Ctrl + Click` с наглядным компасным кругом и стрелкой направления.
