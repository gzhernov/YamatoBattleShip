# Full Screen Tactical Map Historical Overlay Task

## Задача
Добавить тактическую карту на весь экран с отображением траектории движения цели и залпов в стиле исторических схем.

## Что нужно продумать
- Структуру полноэкранной карты и сценарии входа/выхода без потери управления боем.
- Отображение траекторий целей, истории маневров и временной последовательности залпов.
- Набор слоев карты и условных обозначений в единой исторической стилистике.
- Масштабирование, навигацию и читаемость при большом количестве объектов.
- Связь карты с текущими системами цели, стрельбы и навигации корабля.

## Ожидаемый результат
Подготовлена задача на полноэкранную тактическую карту с историческим представлением траекторий и залпов для детального анализа боя.
