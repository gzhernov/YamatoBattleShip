# Global Map Mode Task

## Задача
Добавить режим глобальной карты.

## Что нужно продумать
- Структуру глобальной карты: регионы, острова, зоны интереса, маршруты и точки входа в локальные сцены.
- Переходы между глобальной картой и локальной картой: условия входа, выход обратно, сохранение позиции и контекста.
- Как связать остров на локальной карте с формой, положением и масштабом острова на карте региона.
- Какие данные нужны для соответствия региона и локальной сцены: контур острова, береговая линия, глубины, ориентиры и точки спавна.
- UI режима глобальной карты: выбор региона, подсветка доступных зон, отображение маршрута и состояния перехода.
- Ограничения MVP, чтобы сначала получить понятную навигацию между картами без полной стратегической симуляции.

## Ожидаемый результат
Подготовлена задача на проработку режима глобальной карты, переходов на локальную карту и правил создания островов в соответствии с картой региона.
