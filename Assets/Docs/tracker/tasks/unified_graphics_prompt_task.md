# Unified Graphics Prompt Task

## Задача
Разработать промпт генерации графических материалов в едином стиле.

## Что нужно продумать
- Общую художественную стилистику для проекта: настроение, эпоха, тон и визуальные акценты.
- Набор постоянных параметров промпта: палитра, освещение, ракурс, детализация, уровень реализма.
- Ограничения и запреты в промпте, чтобы избегать выбивающихся по стилю результатов.
- Вариативные блоки промпта под разные типы материалов: фон меню, интерфейсные иллюстрации, промо-изображения.
- Формат промпта и правила его использования командой для получения повторяемого результата.

## Ожидаемый результат
Подготовлена задача на создание универсального промпта для генерации графических материалов, который обеспечивает единый визуальный стиль и предсказуемое качество итоговых изображений.
