# ShipHeelVisualController Rudder Return Task

## Задача
Исправить некорректную работу `ShipHeelVisualController` при возврате руля.

## Проблема
При возврате руля корабль резко возвращается в нейтральное положение по крену.

## Что нужно продумать
- Почему целевой крен сбрасывается слишком резко при уменьшении угла руля.
- Нужно ли сглаживать возврат к нейтрали отдельно от набора крена.
- Как учитывать текущую скорость, скорость поворота и фактическое состояние руля.
- Как избежать визуального рывка без изменения основной кинематики корабля.
- Какие параметры вынести в настройки, чтобы поведение можно было геймплейно тюнить.

## Ожидаемый результат
Корабль плавно возвращается из крена в нейтральное положение при возврате руля, без резкого визуального скачка.
