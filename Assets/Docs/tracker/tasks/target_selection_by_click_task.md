# Target Selection By Click Task

## Задача
Добавить выделение цели по клику.

## Что нужно продумать
- Как игрок выбирает цель: клик по кораблю в мире, по маркеру цели или по элементу интерфейса.
- Визуальную обратную связь при выборе: рамка, подсветка, маркер, изменение состояния UI-панели цели.
- Правила смены и снятия выделения: повторный клик, клик в пустое пространство, уничтожение цели или потеря контакта.
- Связь выбора цели с текущими системами наведения, сопровождения, камеры и боевого интерфейса.
- Поведение системы при наличии нескольких потенциальных целей рядом и при перекрытии коллайдеров или UI.

## Ожидаемый результат
Подготовлена задача на реализацию выделения цели по клику с понятным сценарием выбора, визуальным подтверждением для игрока и интеграцией с текущим боевым интерфейсом.
